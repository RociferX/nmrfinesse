# NMRFinesse 使用教程

本教程对应当前源码界面。运行版本见「帮助 → 关于」；源码与 AppImage 分别更新，安装包包含的功能以其发布说明为准。左侧目录可跳转到对应章节。

### 1.2 运行条件与范围

处理原始谱需要另行安装 NMRPipe；NUS 重构还需要 SMILE 插件。软件可查看已有 1D/2D/3D 谱图、处理峰表和导出 UCSF 文件；这些操作与重新处理原始数据分开。

软件组织项目、实验、数据和数据组，支持 Bruker 导入、FID/谱图生成、质量报告与峰挑选。批量处理入口仅支持独立的 2D 数据；3D 按单份数据处理。峰重叠解耦、去卷积、结构解析和自动指认不在当前功能范围内。

## 2. 页面、窗口与注释

### 2.1 左侧选什么，中间显示什么

| 左侧层级 | 中间页面与主要操作 |
| --- | --- |
| 工作区 | 新建、打开或选择最近项目 |
| 项目 | 新建实验，查看实验/数据数量及最近运行 |
| 实验 | 上方单个/分段/批量导入，下方样品数据表 |
| 样品数据或其子目录 | 当前数据的处理流水线 |
| 数据组 | 批量处理、组参数与组结果 |

右侧为谱图查看器；任务日志位于中间栏下方，随当前选择切换。数据页顶部合并显示「处理样品数据 · 流程 · 项目/实验」。新建项目在欢迎页、新建实验在项目页；UCSF 导出在「工具」菜单。

### 2.2 窗口与字号

默认以普通窗口打开，尺寸按 1080p 逻辑工作区设定上限并扣除任务栏和窗框。小屏使用滚动条查看超出内容；大屏初始窗口保持该尺寸。自动字号在普通窗口使用基准，最大化/全屏时重新适配；普通拖动窗口大小不重新缩放字号。手动字号优先。

三栏分界可拖动。应用对话框居中、保持在主窗口上方并阻止操作后方界面；菜单和下拉列表在触发位置展开。浏览使用系统原生文件/目录窗口，从已填写路径或相关默认目录开始。

### 2.3 title 与注释

新导入数据默认以源文件夹名命名，手动填写名称优先。Bruker `title` 作为默认备注并显示在左树；已有手动备注不被自动填充覆盖。

title 的原始行是排版片段：宽度够时用 ` | ` 连成一行，不够时优先在原始行间换行。单条原始行本身过长时继续必要换行，避免内容被截断。图层、谱图文件、比对、颜色按钮和导出摘要的悬浮提示显示对应 title、源数据及完整路径。

中间顶部直接显示注释内容和「编辑注释」，没有单独的「注释：」标题。短字段整体换行；数据备注采用上述 title 排版规则，存储原文不变。

## 3. 建项目与导入数据

### 3.1 新建项目和实验

1. 选择工作区，在欢迎页点「新建项目...」，输入名称并确认；或使用「文件 → 打开项目...」。
2. 选中项目，在项目页输入实验标题并点「新建实验」。
3. 选中实验，在上方导入区域选择相应入口；导入后的数据出现在下方表格和左树。

### 3.2 三种导入入口

| 入口 | 选择的目录 | 导入结果 |
| --- | --- | --- |
| 单个导入 | 直接包含 `acqus` 的 Bruker 数据目录 | 一条数据；可指定名称 |
| 分段/重复导入 | 顶层无 `acqus`、至少两个子目录各含 `acqus` 的容器 | 同一次采集的互补分段或兼容重复实验，合并为一条数据 |
| 批量导入 | 一个包含独立数据的总目录，或逐次添加多个数据目录 | 多条独立数据；勾选「导入并成组（仅2D）」才组成数据组 |

三列的浏览和主导入按钮位于顶部，说明在下方。批量并成组默认关闭；批量列表为空时隐藏，添加后最多显示四行并可滚动。批量入口跳过 3D 并报告原因，单个失败不影响其它数据。

### 3.3 原始路径与识别结果

默认勾选「链接原始数据到项目」，以只读链接为主，必要时复制；取消则仅引用源目录。使用链接或引用时应保持源目录可访问，重新导入另一条数据不会修复旧数据的断链。

导入后核对维度、实验类型、采样模式和布局证据。普通目录应包含相应采集参数及 `ser`/`fid`；NUS 需要 `nuslist` 或采集参数明确指名的日程。不把已有 NUS 当作普通采样数据导入。日志会解释拒绝的布局或不一致参数。

## 4. 处理流水线、报告与状态

### 4.1 按步骤处理

1. **生成 FID**：生成并运行转换脚本，将 Bruker 原始数据转换为 NMRPipe FID；3D 可使用单文件或切片布局。
2. **生成谱图**：自动选择或使用指定处理参数生成终谱；NUS 路径包含 SMILE 重构。需要时先设置「直接维范围」；常见蛋白质 1H 默认窗口为 6.5–10.5 ppm，按当前数据核对。
3. **峰挑选**：检测峰、保存强度/SNR 并生成峰表；后续查看和导出见第6节。

GUI 暂不提供 SMILE 参数优化、排序或按名次重跑；生成 NUS 谱图仍使用 SMILE 重构。

### 4.2 人工脚本、报告和日志

「人工」打开该步骤脚本，编辑后保存运行；成功后比较本次与前一次成功脚本的参数变化。失败运行不被标成参数已成功应用。

「重新运行终脚本」复用已生成的最终脚本，跳过重新优化。间接维翻转只作用于对应间接维处理；按界面所示核素选择。查看「报告」可展开质量结论、参数及运行信息。成功处理会刷新对应数据的谱图，日志仍按当前选择显示。

独立数据操作写该数据日志；数据组操作显示组日志和成员结果。失败步骤可点「查看日志」。

### 4.3 “待更新”是什么意思

文件存在，但当前输入或脚本与上次成功快照不同，会显示「待更新」。原因直接指出缺失路径、缺失/新增/变化的文件或脚本；下游同时显示上游原因。新成功记录保存逐文件指纹；旧多文件记录证据不足时会明确说明无法确定具体文件。

「设置 → 软件设置 → 简单模式」只按产物是否存在判断可用步骤，关闭指纹和新旧比较。它不会修复原始数据或重新生成结果。

## 5. 谱图查看与比对

### 5.1 通用操作与坐标

选择数据自动加载当前谱图。文件与图层、显示/切片控制、峰工具/峰表可分别折叠；峰区默认收起。放大按钮让绘图区占用更大区域，再点恢复。

- 滚轮缩放，中键拖动平移；2D/3D 可左键框选放大。
- Contour start 控制等高线起点百分比，Levels 控制级数；正负峰可分别隐藏。
- Aspect 为0时自由缩放；键入数值按 Enter 应用，离焦或 Esc 取消未提交输入。
- 「Full view」恢复完整视图；超过约150%放大时，左上出现全谱概览小框。
- 文件名、图层和比对条目上悬浮，可区分不同实验下同名谱图。

2D 的 F1 是间接维、F2 是直接维；3D 的 F1/F2 是间接维、F3 是直接维。坐标按逻辑维度显示，同核维用 x/y/z 区分。常规 ppm 横轴左大右小。

### 5.2 直接查看 1D 谱

1D 默认 Aspect 为0.02，零强度居中，初始优先显示完整横坐标，水峰可暂时超出纵轴。锁定 Aspect 后，显示全谱横轴仍可继续等比缩小，直到完整强度范围也容纳；Full view 恢复初始视角。

自由 Aspect 下，滚轮纵向缩放倍率为横向倍率的1.5次幂。1D 和2D的 Aspect 分别保留；中键仍可平移。相位预览只改变显示，不写回原始数据或谱文件。

### 5.3 2D/3D 的1D条带与调相

普通2D/3D十字虚线无需按键即可跟随鼠标。开启「1D」后，在谱图内**按住左键**移动十字线与上方/右侧切片；松开后固定，移出谱图区仍保留。

上方条带和右侧条带分别显示所属核素，各有独立 P0/P1。每行 Reset/Copy 只作用于本行；移动切片保留两组设置。此处调相仅用于查看。

3D 默认显示 F3–F2 平面，在切片控件中选择平面、固定轴位置或投影。

### 5.4 两张/三张谱、重叠与SVG

放大后使用「比对」选择参考谱；「加入第三张谱」在右侧子菜单中列出候选谱图。并列时左侧参考、中间当前，各谱缩放和显示控制独立，绘图区等高。

相同核素与方向的2D/3D平面，十字线按相同的**显示ppm**双向联动，包含显示平移；不会联动缩放或改变谱数据。

开启「重叠比对」沿用各谱当前 Contour start、Levels、正负峰与图层显示设置；退出带回调整。颜色按钮、参考谱选择、手动ppm平移和自动拟合用于比较；平移仅作用于显示，不改原始谱及文件头。重叠时隐藏峰工具/峰表，退出恢复。

重叠完整视图覆盖各谱联合范围，使用独立共享 Aspect。「导出重叠图 SVG」可设置范围和宽高比、预览后导出；这是图像导出，与峰表坐标导出、UCSF文件复制分开。

## 6. 峰表、指认与坐标对齐

### 6.1 选峰与编辑

展开「峰工具与峰表」，可选择、框选、添加、删除峰并编辑 Assignment。峰标记默认0.5；大于等于0.5向上每次加0.5，0.5向下每次减0.1，最小0.1。SNR 显示选峰时保存的值，缺值留空；原有噪音和阈值计算保持。

### 6.2 导入.list与恢复CSV

Import peaks 先选择文件。导入 `.list` 需要当前已有选峰，供整体ppm平移匹配；没有则提示先选峰。导入前自动把原始选峰及指认备份为本程序CSV，位于当前数据 `peaks` 目录；备份失败不继续覆盖。

原始选峰与导入峰表可切换，各自保留指认。坐标轴名称注明显示平移，鼠标读数同时给出对齐后ppm和原谱ppm；谱数组与文件头不改，重复导入不累加偏移。低质量对齐不强行删除峰。

选择本程序格式CSV可直接恢复原表，无须先选峰，并清除导入表的显示平移。切换/重新加载数据时按项目保存状态读取。

### 6.3 保存、直接导出和对齐后导出

- **Save peaks**：将当前表写回项目，内部保留强度和SNR。
- **export directly**：导出当前所选峰表的指认与各维ppm。
- **After alignment export**：先选参考 `.list`，用整体平移把当前峰表对齐后导出；当前表和谱图不变。

界面导出的 `.list` 只包含 `Assignment w1 w2 [w3]`，不带强度、体积或SNR。项目内部峰表/定位附件和CSV备份可保留这些指标；不要把外部交换.list当作完整备份。

## 7. 工具菜单与UCSF导出

### 7.1 独立质量检查

- **数据质量检测... → FID文件 / FID文件夹（切片组）**：检查转换后的FID。文件夹只检查直接子级 `*.fid` 切片，不递归；不修改输入，结果写全局日志。
- **谱图质量评估...**：选择已有谱图，查看质量项目与结论，不改谱文件。

这两项可独立于项目运行。原始Bruker目录中的坏FID剔除使用下一项工具。

### 7.2 剔除异常FID并导出NUS…

用于传统采样数据中部分FID异常的情况，支持已验证的2D/3D Bruker布局：AQSEQ=0、直接维复数采集、间接维States/States-TPPI/Echo-Antiecho。不接受已有NUS、动力学/伪维或参数与ser几何不一致的数据。

1. 浏览原始数据目录并检测；检查原始FID行号、采样点坐标和判据。
2. 自动模式选择非有限数据、完整采样点全零及12-MAD孤立尖峰候选；单个相位分量全零和高能量仅提示。手动模式可勾选或取消任意采样点。
3. 核对删除数量和保留比例，选择新输出目录。每个采样点的2/4条相位FID整组剔除，至少保留两个采样点。
4. 导出新的Bruker NUS目录，含 `ser`、`nuslist`、更新采集参数、title和 `fid_selection.json`；不复制旧处理谱。原目录不改，已有目标不覆盖。
5. 从普通导入入口导入新目录，再走NUS/SMILE流程。导出本身不重构谱图。

列表坐标从0开始，3D按acqu2s/acqu3s排列；保留原网格坐标和NusTD。检测后输入变化，需要重新检测。

已有NUS处理路径另有非法/重复采样坐标的源级清理：执行时会改写所用raw中的ser/nuslist，先保存 `.bak` 并写入日志。它与上面的**新目录导出**是两种操作。

### 7.3 导出 UCSF 文件…

打开项目后，从「工具 → 导出 UCSF 文件…」进入；入口不在项目页。按实验勾选一份或多份可用数据，再点「导出」选择目标目录。没有UCSF文件的条目不可选。

后台复制保留项目原件，目标重名加后缀，完成后报告成功和失败。默认位置来自设置中的POKY/Sparky谱图文件夹，也可在导出时另选目录；这是复制已有UCSF文件，不是重新转换或重处理。

## 8. 软件设置

「设置 → 软件设置...」中：

- **工具路径**：为NMRPipe、bruker、proj3D.tcl、pipe2ucsf指定可执行文件/脚本，或留空自动发现；SMILE作为插件显示检测状态。
- **数据总目录**：新导入浏览的默认起点；已填写路径时优先从该路径打开。
- **POKY/Sparky谱图文件夹**：UCSF默认导出位置，可自动发现或手动指定。自动查找使用当前机器环境、工作目录配置和用户常用目录。
- **语言与字号**：语言跟随系统或指定中/英文，按提示重启；手动字号8–18pt，保存后即时应用。
- **默认线宽、对齐容差、SMILE线程和简单模式**：按对应处理/峰匹配任务设置。SMILE线程默认2，低核数机器按上限限制。

路径设置各有「浏览...」，文件与目录分别选择；无效路径使用可用上级目录或主目录。本机设置不会作为项目数据导出。

## 9. 文件位置与排错

### 9.1 输出在哪里

每份数据的 `process` 保存脚本与转换产物，`spectra` 保存终谱及可用的同名UCSF，`peaks` 保存峰表/CSV备份，`report` 保存报告和日志。2D/3D在pipe2ucsf可用时生成UCSF，1D不生成UCSF。

手动导出.list、SVG及UCSF复制使用所选位置。删除项目数据走系统回收站；不要通过删除源目录来清理仍以链接使用的原始数据。

### 9.2 遇到问题先核对

| 现象 | 先检查 |
| --- | --- |
| 无法处理原始数据 | NMRPipe/SMILE检测状态、工具路径和任务日志 |
| 显示待更新 | 原因中的具体输入/脚本路径；区分断链、真实变化与旧记录缺证据 |
| UCSF入口灰色 | 是否已打开项目 |
| UCSF窗口内某条数据不可选 | 是否已有相应2D/3D结果的UCSF文件 |
| 峰表导出灰色 | 是否已加载数据、表内有峰且不是投影查看 |
| 谱图/坐标不符合预期 | 当前文件、3D平面、显示平移和正负峰开关 |

反馈问题时附「关于」版本、桌面/显示会话、复现步骤和相关日志。更多说明见[排错指南](https://github.com/RociferX/nmrfinesse/blob/main/docs/troubleshooting.md)；处理验证与适用边界见[实采证据](https://github.com/RociferX/nmrfinesse/blob/main/docs/evidence/real-data-comparison.md)。
