## 坐标约定

坐标轴按逻辑维度命名：2D 的 F1 为间接维、F2 为直接维；3D 的 F1／F2 为第一／第二间接维、F3 为直接维。同核维度用 x／y／z 下标区分，按直接维、acqu2、acqu3 的顺序分配。NMRPipe 三维存储顺序 (F2,F1,F3) 在读取时转为逻辑顺序；日志中的 axis reorder 是这一步的记录。

## 1. 软件能做什么

- 读取 Bruker 数据，识别维度、实验类型及均匀／NUS 采样。
- 通过 NMRPipe 生成 FID 和谱图，自动选择相位、基线、窗函数等处理参数；NUS 使用 SMILE 重构。
- 提供 FID、采样和谱图质量检查、步骤报告、运行日志及人工脚本编辑。
- 进行峰挑选、三点抛物线亚像素定位、指认编辑、峰表导入和坐标对齐。
- 查看 1D、2D、3D 切片，进行两张／三张谱的并列或重叠比较，并导出峰表、UCSF 和重叠图 SVG。
- 管理项目、实验、样品数据与数据组；批量入口仅支持独立的 2D 数据。

真实处理需要另行安装 NMRPipe，NUS 还需要 SMILE；软件不随包分发这两项工具。

## 2. 界面速览

主窗口分为三栏，栏边界可以拖动调整：

- **左侧项目树**：工作区 → 项目 → 实验 → 样品数据／数据组。选择层级后，中间栏显示对应工具。数据名称下显示 Bruker `title`；悬浮可查看完整说明。对象列默认紧凑，状态列紧邻名称；可拖动表头分界调整列宽，title 随列宽换行并增高。
- **中间处理区**：欢迎页用于新建／打开项目，项目页用于新建实验及导出 UCSF，实验页用于导入数据，数据页显示处理流水线。**任务日志位于中间栏下方**，随当前选择切换。
- **右侧谱图**：选择数据后自动加载当前谱图。文件与图层、显示与切片控制、峰工具与峰表可分别展开或收起，绘图区始终保留。

顶部菜单为「文件」「查看」「工具」「设置」「帮助」。新建项目在中间欢迎页，新建实验在项目页；「帮助 → 使用教程」打开本文。窄屏或大字号下可滚动页面。中间顶部显示注释，短字段作为整体换行，备注保留原始分行。

操作对话框在所属窗口中央打开，保持置顶并阻止操作后方主界面；关闭当前对话框后继续操作主界面。文件／目录浏览使用系统原生选择窗口，从已填写路径或相关默认目录开始；教程与关于窗口中的网页链接由默认浏览器打开。

## 3. 从新建项目到峰表

1. **新建项目**：选择工作区，在中间欢迎页点「新建项目...」，输入名称并确认。项目创建在当前工作区。最近项目列表和「文件 → 打开项目...」可打开已有项目。
2. **新建实验**：选中项目，在中间项目页填写实验标题并点「新建实验」。项目页还显示实验数、数据数和最近运行记录。
3. **导入数据**：选中实验，在常驻导入表单点「浏览...」，选择直接含 `acqus` 等 Bruker 参数文件的数据目录，然后导入。也可右键实验节点选择「导入样品数据...」。数据默认使用源文件夹名，填写的名称优先；`title` 成为默认备注并显示在左树。
4. **核对识别结果**：查看实验类型、采样分类和维度布局。判定证据写在日志；发现识别有误时，先修改相关注释／参数，再继续处理。
5. **生成 FID → 生成谱图**：按流水线顺序运行。需要时先设置直接维范围；常见蛋白质 1H 直接维默认范围为 6.5–10.5 ppm。范围用于优化的选项决定优化与终跑是否使用同一窗口。NUS 谱图生成包含 SMILE 重构。
6. **查看报告和谱图**：展开步骤报告，核对 FID／采样结论、谱图质量分项和实际处理参数。右侧自动加载当前谱图，大型文件在后台读取，3D 默认显示 F3–F2 平面。
7. **峰挑选与导出**：运行峰挑选，检查峰与 SNR，按需修改指认，再使用右侧峰表的导入、保存或导出功能。

流水线顶部的向导提示下一步。步骤失败时可点「查看日志」。重新生成、优化或成功运行人工脚本会刷新对应数据的谱图，日志仍保持你当前选择的范围。

## 4. 流水线步骤与人工处理

### 生成 FID

生成并运行 `fid.com`，通过 NMRPipe 的 `bruker -AUTO` 将原始数据转换为 FID。3D 按采样网格使用单文件或切片布局。CAR 载频在生成谱图阶段查看或修改。

### 生成谱图

按自动选择或人工指定的参数生成终谱。NUS 自动包含 SMILE 重构。完成后可展示谱图或「重新运行终脚本」。后者复用已生成脚本，不重新优化；3D NUS 只重跑间接维部分，3D 均匀采样按提示确认直接维重跑。

需要改变谱中心时，在人工脚本内编辑 CAR。峰位确实呈镜像时，才使用间接维翻转控件并重跑终脚本。2D 勾选框保留当前翻转状态；3D 下拉命令重复选择同一维会取消翻转。程序同步补偿已有 PS 行的相位参数，直接维不参与该翻转。

人工脚本可以打开、编辑并运行。成功后的报告比较上一次成功脚本与当前脚本；失败尝试不会写成成功应用的参数。

### SMILE 优化

「SMILE 优化」是仅供 2D NUS 的可选参数扫描和排名，支持不同排序目标。它不会自动替换活动谱；选择候选后再运行相应脚本。3D NUS 可正常重构，但不提供这条扫描入口。

### 峰挑选

自动检测峰并保留峰高和选峰时的 SNR，亚像素定位采用三点抛物线。可调整阈值重跑，也可通过步骤行「参考谱」选择已有峰表的数据，以保留匹配峰；参考不可靠或没有共同核素时保留检测结果并说明。旁边「清除」取消参考约束。

步骤状态包括未就绪、可运行、运行中、已完成、失败和已过期。输入或参数变化会使受影响的下游步骤过期，需要重新运行。

## 5. 查看、缩放与谱图对比

- 滚轮缩放，中键拖动平移，Full view 恢复全谱；Contour start 调整等高线起点，Levels 调整级数，Aspect 调整纵横比，`0` 为自由比例。
- 数值输入按 Enter 应用，离焦或 Escape 取消草稿；箭头按钮即时调整，Aspect 支持 `0.8` 等小数。
- 1D 全谱的纵轴零点居中；自由 Aspect 下纵向滚轮缩放速率为横向的 1.5 倍。1D／2D 均支持中键平移，切回 2D 时直接维高 ppm 保持在左侧。
- 放大超过 150% 后，左上角出现全谱小框。点击或拖动小框定位，Full view 恢复全谱并隐藏小框。
- 「放大」让绘图区扩展到左侧，再次点击恢复。3D 可选择平面、切片并显示投影。
- 对比支持两张或三张谱、独立颜色、正负峰控制、并列及共坐标重叠。完整视图覆盖各谱联合范围，并列绘图区等高；重叠时隐藏峰工具与峰表，退出后恢复。
- 重叠图 SVG 导出可设置 ppm 范围、长宽比并预览，默认名称标明谱名与颜色。

独立查看器无需项目，安装后运行 `nmrfinesse-viewer` 或 `python -m viewer`，支持拖放 `.ft1`／`.ft2`／`.ft3` 文件。

## 6. 峰表指认、导入和导出

展开右侧「峰工具与峰表」查看、选择、框选、添加或删除峰，并编辑 Assignment。SNR 显示选峰时保存的结果，缺值留空。

- **导入 `.list`**：Import peaks 先选择文件，再检查当前是否已有选峰。程序先将原始选峰的指认、坐标、强度和完整精度 SNR 自动备份到当前数据 `peaks` 目录的 `<exp>-<data>_picked_<时间>.csv`，再计算到导入峰表的整体平移。备份失败会停止导入。
- **切换峰表**：下拉框切换「原始选峰」和「导入峰表」，各自保留指认。原表使用原谱坐标，导入表使用参考坐标，标记均落在对应谱峰。轴名注明平移量，鼠标读数同时显示对齐后与原谱 ppm；谱数据和文件头不变，重复导入不累加平移。
- **恢复 CSV**：Import peaks 选择本程序格式的 CSV，直接恢复原表，无须先选峰，同时清除参考表和显示平移。表与定标保留在当前加载会话；重新加载或选峰会重新读取项目峰表，原表可从 CSV 备份恢复。
- **导出 `.list`**：Export peaks 的直接导出保存当前所选表；「对齐后导出」先选参考 `.list`，用与导入相同的方法整体平移，再选择保存位置。导出只含指认和各维 ppm，不带强度或 SNR；当前表和谱文件不变。
- **保存峰表**：Save peaks 将当前表写回项目并记录一次手动峰表运行。内部保存仍保留强度和 SNR。

## 7. 分段采集与重复实验叠加

互补的分段 NUS，或同一套参数和采样点的重复采集需要合并时，使用实验导入页的「分段数据或重复实验叠加导入」。右键实验的导入对话框也有相同选项。

选择的容器顶层不含 `acqus`，下方至少两个子目录各含一套数据。程序会识别此结构；不满足条件会提示。导入后合并成一条数据，只运行一套 FID／谱图流程。多份独立数据使用下一节的批量入口。

## 8. 数据组与批量导入（仅 2D）

实验页「批量处理」区右侧的「浏览...」可逐个加入独立数据目录，「清空列表」可移除全部候选。「批量导入并成组」默认关闭；勾选后，数据导入同一组，可整组处理。项目树中也可增删组成员。

点击「批量导入」后显示总数、成功和失败汇总。非 2D 数据会跳过并说明，单份失败不会中断整组。单独处理组成员写成员日志，整组运行写组日志。

## 9. 工具菜单

- **数据质量检测**：选择 FID 文件或 FID 文件夹（切片组）。文件夹只检查直接包含的 `*.fid`，不递归子目录。结果写全局日志，不依赖项目，不修改 FID 或处理记录。
- **谱图质量评估**：读取已有谱图，给出质量分项与结论。

## 10. 软件设置与路径浏览

打开「设置 → 软件设置」：

- **工具路径**：NMRPipe、bruker、proj3D.tcl、pipe2ucsf 每行均有「浏览...」，选择可执行文件或脚本；也可直接输入路径，留空沿用自动发现。SMILE 是插件，只显示检测状态。
- **数据总目录**：新导入浏览的默认起点。已填写路径时从该路径打开，无效路径使用可用上级目录或用户主目录。
- **POKY/Sparky 谱图文件夹**：UCSF 导出的默认目录。「浏览...」手动指定，「自动查找」读取当前机器的用户环境和 POKY 工作目录配置，支持含空格和其它磁盘的目录。留空时自动发现，未找到时从主目录开始浏览。
- **界面语言与字号**：语言可跟随系统或指定中／英文，按提示重启应用；字号可自动或手选 8–18 pt，保存后即时应用，大字号下可滚动。
- **各核默认线宽与对齐容差**：用于相应优化和峰匹配步骤。
- **SMILE 线程数**：默认 2，上限按机器核数计算，低核数机器使用 1。

每个路径都有对应的浏览按钮，文件和文件夹分别选择。浏览从已填写路径或对应默认目录打开，设置写入本机配置。

## 11. UCSF 导出与产物位置

选中项目，在中间项目页点击「导出 UCSF 文件…」，按实验勾选一份或多份数据，也可勾选实验批量选择其可用数据。点「导出」后再选择目标文件夹。无 UCSF 文件的条目不可选。后台复制保留项目原件，重名自动加后缀，完成后列出成功和失败结果。

每份数据的 `spectra` 目录保存 NMRPipe 终谱（`.ft1`／`.ft2`／`.ft3`）。2D／3D 在 pipe2ucsf 可用时同时生成同名 `.ucsf`。峰表 CSV 备份在 `peaks` 目录，手动导出 `.list` 时自选位置。项目文件、脚本、运行记录和日志均保存在项目内；删除项目数据走系统回收站。

**NUS 坏采样点清理会改写源数据。** 程序在原始目录中按整行删除 `ser` 与 `nuslist` 的坏点，事先保存 `ser.bak`／`nuslist.bak`，已有 `.bak` 不覆盖。日志记录 `Source cleanup …(backup .bak)`。原始数据只读或不能接受改写时，先使用副本。

## 12. 使用边界

批量仅限 2D。峰重叠解耦、去卷积、结构解析和自动指认不在当前范围内。谱图处理与质量报告需要结合实际数据检查，统计与科学结论由你的分析流程完成。处理证据见仓库 `docs/evidence/real-data-comparison.md`。

## 13. 出问题先看哪里

先看中间栏下方任务日志，失败步骤可点「查看日志」。缺少工具时检查设置路径；怀疑原始数据时使用「工具 → 数据质量检测」。项目内脚本、运行记录和 `log.txt` 保存输入、参数及结果线索；更多说明见仓库 `docs/troubleshooting.md` 和 `docs/faq.md`。
