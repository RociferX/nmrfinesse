# NMRFinesse 使用教程

本教程对应当前源码版。在「帮助 → 使用教程」中，点击左侧目录可跳到所需操作。使用安装包时，在「帮助 → 关于」查看运行版本，并用发布说明核对该版本包含的功能。

### 1.2 先走一遍完整流程

处理 Bruker 原始数据需要 NMRPipe，重构 2D 或 3D NUS 数据还需要 SMILE。已有谱图可以直接在右侧「文件」菜单中打开。启动时，同一窗口先显示加载进度，准备完成后进入工作区。

1. 在欢迎页新建项目，选中项目后在中间创建实验。
2. 选中实验，用「单个导入」添加一个包含 `acqus` 的 Bruker 目录。导入后在左树选中数据。
3. 在「自动处理」依次运行「生成 FID」和「生成谱图」。有可用的 2D 或 3D 谱图后，可以运行「峰挑选」。
4. 用右侧查看器检查谱图，展开「峰工具与峰表」查看或修订峰表。用「Save peaks」保存项目内编辑，需要交给 POKY/Sparky 时再导出 `.list` 或复制已有 UCSF。

## 2. 工作区、页面与注释

### 2.1 左树每一层的用途

| 选择 | 中间显示 | 常用操作 |
| --- | --- | --- |
| 工作区 | 欢迎页 | 新建、打开、继续最近项目 |
| 项目 | 项目概况 | 建实验，查实验和数据数量，回顾最近运行 |
| 实验 | 导入表单和样品数据表 | 添加数据，核对名称与状态 |
| 样品数据 | 该数据的处理页 | 自动处理、复用参考脚本、查报告 |
| 数据组 | 组注释与整组处理 | 对照组成员、设置参考、指定整组截止步骤 |
| 数据子目录 | 所属数据的处理页 | 定位原始文件、脚本、谱图、峰表和报告 |

「文件」可打开、保存项目、切换最近项目或退出。左树右键提供重命名、删除及与当前层级相关的操作。数据或目录支持在文件管理器、终端中打开。双击谱图文件可直接加载。

### 2.2 窗口与日志

默认打开普通窗口，按 1920×1080 物理像素安排三栏并适应任务栏。拖动三栏分隔条可分配宽度，拖动中间的水平分隔条可调整日志高度。工作区较小时可整体滚动。

日志随选择切换。选中数据看该数据的步骤，选中组看整组进度和汇总。「清空」清除当前作用域日志，单数据日志也会从磁盘清空。「停止当前任务」发出取消请求。已经生成的文件可在相应数据目录检查。

### 2.3 Bruker title 与编辑注释

项目可记录样品和蛋白信息，实验可记录仪器与实验条件，样品数据可记录重复编号、缓冲液、pH、温度、核素、采样模式和峰符号等。选中相应节点后点「编辑注释」，填写后保存。直接维范围、相位等处理参数在对应步骤中设置。

源文件夹名是默认数据名称，手动填写的名称优先。Bruker `title` 作为默认备注，在左树数据名下显示。多行 title 能放下时用 ` | ` 连成一行，否则优先沿原有边界折行。谱图文件、图层、比对项和颜色按钮的悬浮提示也会显示关联的 title 和路径，可用来辨认同名文件。

## 3. 建项目与导入数据

### 3.1 创建层级与选择导入方式

在欢迎页新建项目，再在项目页输入实验标题并创建实验。一个实验可放多份独立样品数据。选中实验后，从上方三种入口导入，并用下方样品数据表核对结果。

| 入口 | 选择什么 | 用于什么 |
| --- | --- | --- |
| 单个导入 | 直接含 `acqus` 的目录 | 导入一份样品数据，可选填显示名称 |
| 分段/重复导入 | 顶层无 `acqus`，至少两个子目录各含 `acqus` | 将互补分段或兼容重复采集作为一条数据处理 |
| 批量导入 | 一个包含独立数据的顶层目录 | 一次扫描多份数据，每份建立独立记录 |

分段导入用于后续联合转换和合并，要求核素、维度和采集参数兼容。批量导入保留各样品独立的脚本、结果和报告。

### 3.2 批量筛选、清除和自动成组

1. 在批量栏点「浏览」，选择一个顶层目录。扫描到的候选显示在可滚动列表中。
2. 用下拉保留全部、仅 1D、仅 2D、仅 3D 或任意两种维度。列表首行 `All` 可勾选或取消勾选当前筛选结果中的全部路径。只勾了一部分时，`All` 显示半选。也可按 `Ctrl+A` 全勾选，再点「清除勾选项」移除。
3. 「批量导入」导入当前过滤后的整个列表。需要整组处理时，勾选「按维度分别成组」。该选项默认关闭，开启后 1D、2D、3D 分别成组。
4. 用左树和日志核对结果。某个目录失败时，可根据日志定位该目录。

### 3.3 原始文件、NUS 日程与导入核对

「链接原始数据到项目」默认开启，优先建立链接，必要时复制。取消勾选时项目直接引用源目录。依赖源目录的项目应保留原位置和读取权限。同一个目录再次导入成新条目后，旧条目仍使用原来的路径记录。

导入后核对维度、实验类型、核素及采样模式。`acqus`、间接维采集参数和 `fid` 或 `ser` 共同决定数据布局。NUS 应有 `nuslist` 或采集参数明确指名的日程。源目录缺文件、布局不匹配或分段参数冲突时，先读导入日志。

## 4. 自动处理、参考脚本和数据组

### 4.1 自动处理的每一步

| 步骤 | 做什么 | 到哪里检查 |
| --- | --- | --- |
| 生成 FID | 用转换脚本把 Bruker 原始数据转换为 NMRPipe FID。3D 可使用切片输出 | `process` 中的 FID 和转换脚本 |
| 生成谱图 | 完成加窗、变换、相位等处理并生成终谱。NUS 路径使用 SMILE 重构 | `spectra` 中的终谱、可用投影及 UCSF |
| 峰挑选 | 检测峰并记录坐标、强度和 SNR | `peaks` 产物和右侧峰表 |

「直接维范围」决定处理结果保留的直接维区间，单位为 ppm。常见蛋白质氢谱预设窗口为 6.5–10.5 ppm，请核对待观察峰是否在范围内。「间接维翻转」用于修正指定间接维的方向。

峰挑选阈值以噪声倍数（σ）表示。调高会减少进入候选的弱信号。「峰挑选」栏的「参考谱」用于参考峰匹配约束。需要比较两张谱的外观，使用右侧「比对」。需要沿用处理参数，使用「参考脚本处理」。1D 流程截止到生成谱图。

分段数据的「组间场漂校正」以第 1 段为基准，为其它段填入转换偏移。GUI 的 NUS 流程使用 SMILE 重构，当前界面提供线程设置。

### 4.2 脚本编辑、重跑与报告

- **脚本编辑**打开当前步骤脚本。编辑前核对参数所属维度，保存并运行后到报告确认实际应用的参数。
- **重新运行终脚本**复用已生成的最终处理脚本，适合重复执行已经确认的方案。要从当前数据重新自动选参，使用步骤的运行入口。
- **报告**用于核对输入、参数、输出和质量评估。**查看日志**可定位失败阶段，**重试**用于处理原因后再次运行。成功处理后，正在查看的对应结果会刷新。

### 4.3 单数据复用参考脚本

在数据页右栏选「参考脚本处理」。这个入口适合同一系列样品需要沿用一套处理方法、随后比较峰位的情况。

1. 选择同一实验内的另一份数据。维度、按维度顺序排列的核素及采样模式须一致，候选还须有已保存的谱处理脚本或相应的成功运行快照。3D NUS 核素序列不同会得到空候选。
2. 在「处理到」选择 FID、谱图或峰挑选。仅生成 FID 时会复用参考 `fid.com` 的转换参数，生成谱图时还会复用参考谱处理脚本。目标数据使用自己的输入和输出位置。
3. 需要单独调整时点「直接维范围」或「相位」。弹窗从参考值开始，修改值用于本次目标数据。P0 是常数相位，P1 随坐标变化，按各逻辑维分别填写。
4. 「自动相位」默认关闭。开启后在目标 FID 转换完成时搜索各维相位，再将结果代入参考脚本。窗函数、填零等其它参数继续采用参考脚本。
5. 点「运行」，看当前数据的状态与日志。参考处理报告含参考来源、脚本快照及 SHA256、覆盖参数、引擎日志和输出。自动相位搜索记录也会关联到报告。

### 4.4 创建、维护与处理数据组

按住 `Ctrl` 多选同一实验内的同维度数据，右键「创建数据组」。创建后左树展开并选中新组。组的右键菜单可添加同维度成员、重命名、仅删除组标签，或将组和成员移入回收站。成员右键可移出组并保留为独立数据。多选右键删除可一次确认后移除所选数据及其产物。

组注释表每列对应一个成员。备注在首行，其余字段只显示至少有一份填写的行。温度行小按钮按 **`·` 原顺序、`>` 从低到高、`<` 从高到低** 循环。注释表和左树同步，空值或无法识别的温度在排序后排末尾。悬浮可查看符号含义。

- **自动优化组内数据**为每份数据自动选参，「处理到」决定截止步骤。2D 默认最多同时处理 5 份，设置允许 1–10。1D、3D 依次运行。
- **按参考数据处理整组**为成员复用指定参考脚本，逐份运行。直接维范围、相位各有逐成员表格。自动相位在各自的 FID 转换后执行。
- 整组有汇总，各成员有独立状态、日志和报告。单个失败时查该成员日志，其它成员继续。移出或软删除的成员从处理名单排除。

### 4.5 理解「待更新」

「待更新」表示已有产物对应的输入或脚本与当前版本不同。原因可指向失效路径、变化或缺失的文件，或者上游步骤。旧记录缺逐文件证据时，界面会标出可确定到的范围。

输入路径恢复后重新核对状态。确实修改了输入或脚本时，从最早受影响的步骤重跑。「简单模式」用于只按产物是否存在判断步骤可用性。

## 5. 谱图查看、切片与比对

### 5.1 打开文件与控制视图

右侧「文件」可打开当前数据谱图、打开任意谱图或清除显示。项目谱图也可从文件列表、左树或「展示谱图」打开。「文件」列用于选择文件，「图层」列用于控制当前绘图中各谱图的显示。点「放大」扩大绘图区，再点关闭可回到三栏。

| 控件 | 用途 |
| --- | --- |
| 滚轮、中键 | 缩放，按住中键拖动可平移 |
| 2D/3D 左键框选 | 普通查看模式下放大矩形区域 |
| Contour start | 等高线起始强度百分比。降低可显示更弱信号，也可能显示更多噪声 |
| Levels | 等高线级数，默认12层；已保存谱图沿用其设置 |
| 正峰、负峰开关 | 分别隐藏对应符号的等高线 |
| Aspect | 设置横纵比例。按 Enter 应用，0 为自由比例 |
| Full view | 恢复当前模式的完整或初始视图 |

放大超过约 150% 后左上会出现全谱概览，用于确认正在看的位置。2D/3D 十字虚线和下方读数显示鼠标位置的 ppm。ppm 横轴通常左大右小。2D 的 F2、3D 的 F3 是直接维，同核维用 x/y/z 等标签区分。

### 5.2 查看 1D 与取 1D 切片

直接打开 1D 时，横轴为 ppm，纵轴为强度，零线居中。默认 Aspect 0.02，初始优先显示完整横轴，水峰可能超出纵轴。继续缩小可查看完整强度范围。自由比例下滚轮的纵向变化比横向更快，中键可平移。

在 2D/3D 谱图中点「1D」，上方和右侧条带各展示一条穿过十字线的切片。**按住左键拖动**改变切片位置，松开后固定。上、右条带可按对应核素独立预览 P0/P1，各行 Reset 和 Copy 只作用于本行。预览相位用于显示，正式相位在处理流程中设置。

### 5.3 3D 投影与切片

选中 3D 数据时，优先打开已有 2D 投影作概览。要查看第三维位置，点「展示谱图」或在文件列表打开 `.ft3`。

完整 3D 初始平面为 F2–F3，固定 F1。平面下拉决定展示哪两维。余下一维用滑块、点号或 ppm 选择，三个位置控件同步。投影适合寻找信号区域，切片适合观察具体第三维位置。操作峰表前，先核对当前视图。

### 5.4 并列比较两张或三张谱

放大后打开「比对」，可选项目结果谱，也可「加载谱图…」。并列时分别调整各谱的范围和显示参数。「加入第三张谱」和「移除第三张谱」改变视图数量。

核素和方向兼容的平面按相同的**显示 ppm**同步十字线，方便在不同谱中定位同一坐标。各面板可独立缩放。悬浮到候选文件或图层可检查 Bruker title 和路径。

### 5.5 重叠、显示平移与 SVG

1. 在并列比对中先调好每份谱的 Contour start、Levels、正负峰及图层可见性，再开启「重叠比对」。重叠继承这些配置，退出时带回调整。
2. 用颜色区分各谱。默认固定当前谱，也可启用「以比对数据为参考」并选定固定谱。
3. 「手动调整」可按坐标轴平移指定谱。自动拟合检测临时峰并估算整体 ppm 平移，适合先得到一组起始偏移。两者调整的是绘图坐标，重叠时峰表工具收起。
4. 重叠全视图覆盖各谱联合范围，可调共享 Aspect。「导出重叠图 SVG」可设定范围和比例并预览，用于导出矢量图。峰表和 UCSF 各有对应入口。

## 6. 峰表、指认与坐标对齐

### 6.1 读峰表和手动编辑

完成「峰挑选」后展开「峰工具与峰表」。Assignment 是用户指认，ppm 列按谱图维度给出峰位置。SNR 为选峰时保存的信噪比，缺值留空。

| 操作 | 用途 |
| --- | --- |
| 点击峰或峰表行 | 定位相应标记或记录 |
| Select mode | 按住左键拖框，多选框内峰 |
| Add peak mode | 点击加峰，优先吸附附近峰顶，找不到明显峰时用点击坐标 |
| Delete selected | 删除所选峰行，自动峰和手工峰均可选 |
| Assignment | 在行内输入框编辑指认，点击列标题切换图上的指认标签 |
| Mark size | 调整标记大小，默认 0.5、最小 0.1，标记随谱图缩放 |

框选峰、加峰和 1D 切片各有左键模式。要恢复普通框选缩放，先退出当前模式。编辑后使用「Save peaks」写回项目。

### 6.2 导入 POKY/Sparky 峰表并对齐

1. 先在当前数据挑峰，得到供匹配的原始峰表。
2. 用「Import peaks」选择 `.list`。程序先将原表和指认备份为项目 `peaks` 目录中的 CSV，再比较两表估算整体 ppm 平移。
3. 用峰表来源下拉在原始选峰与导入表之间切换。两份指认分别保存。轴名标注显示平移，鼠标读数可同时查看对齐后 ppm 和原谱 ppm。重复导入会重新估算本次平移。
4. 导入本程序格式的 CSV 可恢复原表并清除导入表的显示平移。这条恢复路径可在尚未选峰时使用。

### 6.3 区分保存、直接导出与对齐后导出

- **Save peaks**保存当前表到项目，强度、SNR 等保留在内部记录或 CSV 备份。
- **直接导出**将当前所选峰表的 Assignment 和各维 ppm 写入 `.list`，用于交换峰位置。
- **对齐后导出**先选参考 `.list`，估算当前表到参考表的整体平移，写出平移后的 ppm。项目内峰表和谱图继续使用原来的坐标。

GUI 的 `.list` 由 `Assignment w1 w2 [w3]` 列组成。要恢复强度、体积或 SNR，使用内部记录或完整 CSV。

## 7. 工具菜单

### 7.1 数据质量检测与谱图质量评估

**数据质量检测…**用于检查转换后的 NMRPipe FID。可选一个文件或一组 FID 切片的文件夹。文件夹入口检查直接子级的 `*.fid`，结果写到全局日志。

**谱图质量评估…**用于读取已有谱图并查看质量指标和结论。两项工具都可独立于项目使用。需要从 Bruker 原始采集中排除坏采样点时，使用下一项工具。

### 7.2 剔除异常FID并导出NUS…

用于 2D/3D Bruker **均匀采样**中部分 FID 异常、需要保留其余采样点的情况。支持 AQSEQ=0、直接维复数采集，间接维为 States、States-TPPI 或 Echo-Antiecho。`ser` 的布局需与采集参数一致。

1. 选择原始目录并检测，核对从 0 开始的采样坐标、原始 FID 行号和异常判据。
2. 自动模式选出非有限值、整点全零和 12-MAD 孤立尖峰候选。单相位分量为零或能量偏高会作为提示。手动模式可自行勾选或取消整个采样点。
3. 核对删除数量和保留比例。每个采样点关联的 2 或 4 条相位 FID 一起剔除，至少保留两个采样点。
4. 选择新的输出目录。工具写出 `ser`、`nuslist`、更新后的采集参数、title 和 `fid_selection.json`。保留原网格坐标和 NusTD，3D 日程按 acqu2s/acqu3s 轴顺序记录。
5. 用单个导入打开新目录，按 NUS 路径转换并重构。检测后输入发生变化时，请重新检测。

该工具写新目录。已有 NUS 数据的非法或重复日程清理属于处理时的另一操作，会对所用 raw 目录中的 `ser` 和 `nuslist` 先做 `.bak` 备份再改写，并记录日志。

### 7.3 导出 UCSF 文件…

打开项目后，从「工具 → 导出 UCSF 文件…」选数据。弹窗按实验分层，仅已有 UCSF 的条目可勾选。选好后点「导出」，核对目标目录。默认位置来自设置中的 POKY/Sparky 谱图文件夹，也可改选。

工具复制已有文件，目标重名时加后缀，并报告成功和失败。需要先生成 UCSF 时，确认 2D/3D 处理已完成且 `pipe2ucsf` 可用。1D 流程输出 NMRPipe 谱图。

## 8. 软件设置

### 8.1 工具路径与默认目录

顶栏「设置」直接打开「软件设置」。各路径旁可点「浏览…」，工具项选可执行文件或脚本，目录项选文件夹。

| 设置 | 用途 |
| --- | --- |
| NMRPipe 路径 | 定位处理引擎 |
| bruker 路径 | 指定 Bruker 转换程序 |
| proj3D.tcl 路径 | 定位 3D 投影脚本 |
| pipe2ucsf 路径 | 生成可供 POKY/Sparky 打开的 UCSF |
| SMILE 插件 | 查看 NUS 重构插件的检测状态 |
| 数据目录 | 导入浏览的默认起点 |
| POKY/Sparky 谱图文件夹 | UCSF 复制的默认目标。可自动查找、浏览或手填 |

工具路径留空时自动查找。浏览时优先从当前填写的可用路径打开。

### 8.2 界面、匹配、资源和恢复默认值

- **界面语言与字号**。语言跟随系统或手动选择中英文，按提示重启。字号可自动适配或选 8–18 pt，保存后应用。
- **默认线宽和对齐容差**。线宽以 Hz 设置各核素的默认值。容差以 ppm 指定峰对齐与参考匹配允许的距离，值越小匹配越严格。
- **SMILE 线程数和 2D 并行数**。前者控制单次重构的线程，默认 2 并受本机上限限制。后者控制自动模式同时处理多少份 2D 数据，默认 5。
- **简单模式**。按前一步的产物文件判定可用性，适合按现有文件继续操作的情况。
- **恢复默认值**。先将弹窗字段恢复为默认，点「保存」后落盘。软件设置用于当前机器。

## 9. 输出位置与排查

### 9.1 找到并保留结果

| 数据子目录 | 内容 |
| --- | --- |
| `raw` | 项目中的原始数据、链接或副本 |
| `process` | FID、转换和处理脚本 |
| `spectra` | 终谱、可用投影与 UCSF |
| `peaks` | 峰表、内部保存和 CSV 备份 |
| `figures`、`report` | 图、报告、日志和参考处理记录 |

手动导出的 `.list`、SVG 和复制的 UCSF 写入所选位置。删除样品数据走可恢复的回收站路径。仍被其它数据链接的原始目录应保留。

### 9.2 常见问题从哪里查

| 现象 | 先检查 |
| --- | --- |
| 生成 FID 或谱图失败 | 工具路径、原始文件、该数据日志中的首个错误 |
| 参考谱列表为空 | 同一实验是否有同维度、同顺序核素、同采样模式且已保存处理脚本的其它数据 |
| 选择 3D 后只看到 2D | 是否打开了投影，用「展示谱图」或 `.ft3` 进入切片 |
| 看不到预期峰 | 直接维范围、平面和切片、正负峰开关、等高线起点 |
| 峰表导出不可用 | 是否加载对应谱图、当前表是否有峰、是否正在看投影或重叠 |
| UCSF 条目不可选 | 对应数据的 `spectra` 里是否已有 UCSF |
| 显示待更新 | 查看原因以区分路径失效、文件变化或上游脚本更新 |

反馈问题时附「关于」版本、桌面会话、复现步骤和对应日志。详细错误处理见 [排查指南](https://github.com/RociferX/nmrfinesse/blob/main/docs/troubleshooting.md)，实采验证范围见 [实测证据](https://github.com/RociferX/nmrfinesse/blob/main/Chinese_version/docs/evidence/real-data-comparison.md)。
