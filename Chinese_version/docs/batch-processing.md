# 批量处理

批量入口支持1D/2D/3D。浏览顶层目录后可按全部、1D、2D、3D及任意两种维度过滤。勾选成组时按维度分别建组，手动创建或添加组成员也要求同维度。

批量列表首行 `All` 可勾选或取消勾选当前可见路径。「清除勾选项」移除勾选路径，「批量导入」导入当前可见列表中的全部路径。

在左侧选择数据组，在中间页面选择自动处理或参考脚本处理及截止步骤。2D自动处理可并行，默认上限5，设置允许1–10；1D/3D依次运行。参考脚本处理依次运行；1D不执行选峰。删除或移出组的数据不参与后续处理。

自动模式跳过输入指纹仍一致且产物存在的已完成步骤。每个成员独立记录状态、报告、日志；单个失败继续其它数据，停止会取消尚未执行任务。参考模式直接复用参考脚本，可逐成员设置直接维范围、各维相位和FID之后的自动相位。详见[GUI指南](gui.md)。

```python
from workflow.batch import run_batch

result = run_batch(manager, "exp_001", "G1", ["fid", "spectrum"], backend, max_workers=5)
```

程序化入口`max_workers`默认1，最多10，仅2D自动处理使用并行。各成员使用独立后端副本和工作目录。

批量改变数据集；API参数扫描改变同一数据集的处理参数。API的3D NUS参数组合限制保持原样，见[API支持矩阵](external-api/09-limitations-and-roadmap.md)。
