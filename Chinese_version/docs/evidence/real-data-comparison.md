# NMRFinesse 实测证据

## 如何读图

左图是自动处理谱，右图是作者谱。蓝色等高线为正信号，红色为负信号。采用与 Viewer 相同的等对数等高线方式，证据图从自身最高正峰的 8% 起画 12 层；若没有正峰，则取最强负峰的绝对强度。横纵轴每 Hz 等长。三维图展示共同体积内保留符号的 HN、HC、NC 最大绝对值投影。指认峰计数使用完整三维谱。

## 与残基指认的对照

参考坐标来自 BMRB 公开指认。HSQC 采用同一残基的 H 和 N；HNCO 用残基 *i* 的 H、N 配对残基 *i−1* 的羰基 C，并在完整三维谱上核对。两谱按各自扣除中位基线后的最大绝对峰高的 5% 独立检出主符号候选，再与共同范围内的指认坐标做一对一匹配。联合归一化距离不超过 1，各轴容差为 H 0.02 ppm、N 0.20 ppm、C 0.15 ppm。bsCopL 用一半指认残基估计到作者谱的整轴偏移，在 5% 阈值下核对另一半，56 个坐标匹配 55 个。两条 2D 路径共用这一定标，再沿用作者谱到自动谱的整轴偏移。

### 为什么会少选

均匀 2D 自动谱与作者谱找到同一组 108 个指认。自动选出的 F1 EM 10 Hz 窗沿氮维分开了 Gly100 和 His194；受控 NUS 谱在该区域只有一个宽峰。见 [Gly100/His194 局部图](../../../docs/evidence/figures/gly100-peak-shape.png)。

5% 阈值下，四处指认在作者谱找到、在对应自动谱未计入。局部复查保持坐标和容差不变，降低检出阈值，并核对是否存在独立峰顶。

| 指认与路径 | 作者峰顶及处理对照 | 自动谱未计入的原因 |
| --- | --- | --- |
| Ser93 · 受控 2D NUS | 作者谱和均匀自动谱均有独立峰顶，分别为各自最大峰高的 6.24% 和 5.66%。 | 容差内最强响应为最大峰高的 2.55%，约为估计噪声的 2.65 倍，未找到独立峰顶。 |
| Gly100 · 受控 2D NUS | 作者谱和均匀自动谱均沿氮维分开 Gly100 与 His194。 | NUS 谱只有一个宽峰，降低阈值仍未在容差内找到第二个峰顶。 |
| Ile69 · 3D 均匀采样 | 作者峰顶为最大峰高的 6.45%；自动谱在预期位置也有独立峰顶。 | 自动峰高为最大值的 4.57%，低于 5% 阈值，约为估计噪声的 32.7 倍；局部降至 4% 后可找到。 |
| Ser71 · 3D 均匀采样 | 作者谱和自动谱均有独立峰顶，定标后位置接近。 | 作者峰顶到指认的归一化距离为 0.930，自动谱为 1.0013，略超上限 1。 |

### 作者的处理与峰分离

作者谱在部分区域的峰更窄、谷更深。下列数据条目列出可从作者存档核对的额外处理。LP 延长短 FID 后再加窗，有助于同时改善截断旁瓣和峰分离；填零主要改善频域采样。这里的自动谱使用无 LP 的自动选窗，分别核对独立峰顶和峰宽。

## 2D 均匀采样

![2D 均匀采样对照](../../../docs/evidence/figures/uniform2d.png)

### 处理参数

| 维度 | 窗函数 | 基线多项式阶数 |
| --- | --- | --- |
| F2 | SP，off 0.40，end 0.94，二次 | 3 |
| F1 | EM，10 Hz | 3 |

**作者额外做了什么。** 这组二维作者谱在氮维启用前向 LP：`ME_mod=2、NCOEF=32、LPBIN=356`。原始氮维只有 90 个复增量；作者先外推短 FID，再在两维使用平方正弦窗（`WDW=4、SSB=2、FCOR=0.5`），最终 F2/F1 的 `SI` 为 2048/256。其更窄峰形和更深谷底结合了 LP 与加窗的作用，不能全部归因于窗函数。

直接维裁剪至 10.5–6.5 ppm。处理记录包含时域直流偏置修正和最终变换脚本。

## 受控 2D NUS

![受控 2D NUS 对照](../../../docs/evidence/figures/nus75.png)

### 处理参数

| 维度 | 窗函数 | 基线多项式阶数 |
| --- | --- | --- |
| F2 | SP，off 0.45，end 0.98，一次 | 3 |
| F1 | EM，5 Hz | 2 |

SMILE 按采样表重构 F1。F2 使用重构路径的 SP 窗，F1 窗在终处理阶段应用。

本例保留 68/90 个复增量（75.56%）。作者参考使用完整的 90 个复增量，并采用二维均匀采样条目中的 F1 LP 和窗函数。这项对照还包含采样完整度与 LP 的差别。

## 3D 均匀采样

![3D 均匀采样投影对照](../../../docs/evidence/figures/uniform3d.png)

### 处理参数

F3 使用 EM 3 Hz；F2 使用 SP（off 0.60，end 0.94，一次），F1 使用 SP（off 0.60，end 0.90，二次）。直接维裁剪至 10.0–6.0 ppm，终跑使用自动填零和时域直流偏置修正，频域基线校正关闭。

**作者额外做了什么。** 作者对两个间接维分别使用 `LP -fb`，配合一次 SP（off 0.50，end 0.98）；直接维采用二次 SP（off 0.50，end 1.00），并做分步相位校正，其中一阶相位为 43°。碳维还经过逆变换后重新 LP、加窗及变换。LP 和专用窗共同改善窄峰及峰间谷底；相位校正改善吸收线形。脚本另有基线与谱轴参考校正，谱轴平移本身不增加分辨率。

## 实采 3D NUS

![实采 3D NUS 投影对照](../../../docs/evidence/figures/acquired3d.png)

### 处理参数

F3 使用重构路径的 SP 窗（off 0.45，end 0.98，二次）。SMILE 重构间接维，终处理的 F2 使用 EM 20 Hz，F1 使用 EM 5 Hz。频域基线校正关闭。

作者参考为沉积终谱，未附可核对的处理脚本，具体个性化处理步骤尚不能确定。

## 与 POKY/iPick 的选峰结果对照

NMRFinesse 与 POKY/iPick 的 UCSFtool 路径都采用阈值筛选、邻域局部极大值检测和逐轴三点抛物线定位。对 12 张二维 HN 正峰谱使用等效阈值，24 张峰表的候选数全部一致，5,175 条候选记录均在每轴一个网格步内唯一配对。坐标差典型值约为 0.00025 ppm，最大约为 0.00050 ppm，处于 iPick 保留三位小数的精度量级。4 张等阈值表复用结果。

下游可用性核查另有 8,084/8,088 格一致。4 格差异来自同一成员和同一次运行在四个对照中的重复。可用性统计与峰表候选数、坐标配对分别解读。
